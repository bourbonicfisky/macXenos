# macXenos 1.0 — release notes

macXenos is an unofficial macOS port of Xenia Canary with a native Metal
renderer. It runs Xbox 360 games on Apple Silicon Macs, and on Intel Macs
with an AMD GPU (Radeon RX 580 with 4 GB or better). It needs macOS 15 or
later. This is the first public release; it follows beta 8.1 (2026-11-04).

## Install

Download `macXenos-1.0.dmg`, open it and drag macXenos to Applications. The
app is a Universal app, signed and notarized by Apple. From here on it can
update itself: System > Software update in Preferences checks for new
releases.

## What changed since beta 8.1

### Stability

- **Battlefield 3 (Disc 2)** no longer freezes about two minutes into the
  campaign, and no longer crashes in its first load.
- **Ninja Gaiden II** plays its opening cutscene: it crashed or froze there
  on every boot.
- **LEGO Indiana Jones** no longer hangs at the scene change after the
  title screen.
- **Dynasty Warriors 6** no longer crashes when the Musou attack starts.
- **Fallout: New Vegas**, **Fight Night Champion** and **BioShock** boot.
- **Call of Duty: Modern Warfare 2**, **Modern Warfare 3** and **Black
  Ops II** boot (network error codes now match the console's).
- **Infinite Undiscovery** no longer crashes in its work queue.
- **Quantum Theory** and other games that interrupt a waiting thread no
  longer hang.
- **Multi-disc games** find the content their first disc installs:
  Metal Gear Solid V: The Phantom Pain, Grand Theft Auto V (Disc 2) and
  Battlefield 3 (Disc 2) no longer ask for an install that cannot run or
  report a dirty disc.

### Graphics

- **Call of Duty: Modern Warfare 2, Modern Warfare 3 and Black Ops II:**
  no more noise over textures.
- **Dishonored** and **Batman: Arkham Origins:** no more garbage effects.
- **Red Dead Redemption:** no more red and green sparkles in characters'
  hair, and the shadows in the distance are right.
- **Burnout Paradise:** no more shadow line across the road.
- **Grand Theft Auto V (Disc 2)** and **NBA Street Homecourt:** no more
  straight cut across the picture with a broken image below it.
- **Far Cry 2:** no more occasional missing objects.
- **Lost Planet: Colonies:** no black screen on the first boot.

### Speed and memory

- Render targets take only the memory a game actually uses (Red Dead
  Redemption: 971 MB to about 120 MB of render targets).
- Audio decoders take memory only when a game uses them.
- Ultra Street Fighter IV stays at 60 fps with the new, more accurate
  CPU atomics.

### App

- The app, its executable and its settings file are all called macXenos
  (`macXenos.config.toml`; an existing `xenia-canary.config.toml` is
  renamed on first launch, so settings carry over).
- Screenshots (F12) go to `~/Pictures/macXenos/<title ID>` instead of inside
  the app.
- Adding a game folder shows its progress ("Reading game 37 of 182"), and
  multi-disc games keep their disc number.
- The window title and Preferences > About show the version.

## Known issues

- **Need for Speed: The Run** sometimes stops during the opening race on
  M1 Macs (about 1 boot in 3; not seen on M4).
- **Fight Night Round 4:** on some boots the boxers' skin shows a foil-like
  rainbow, or stretched shapes come off a boxer's head.
- **The Elder Scrolls V: Skyrim** crashes now and then (about 1 boot in 5).
- **Jurassic: The Hunted:** a vertical seam can show in the opening walk
  with MetalFX upscaling on.
- See the [compatibility list](../compatibility.md) for every tested game.
