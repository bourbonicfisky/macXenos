# macXenos 1.0 beta 8.1 — release notes

Tagged `macxenos-1.0-beta8.1` on the `codex/metal-foundation-integration`
trunk. A fix release on top of beta 8 (see `1.0-beta8.md`).

## What changed since beta 8

- **Judgment on the M1 Max:** GPU errors no longer cut about a fifth of
  the picture's draws. A change merged with the Intel/AMD work moved render
  pass handling to another thread on every Mac; on Apple Silicon it now
  stays where it was (Intel/AMD Macs keep the faster path; M4 Macs were
  not affected). Mafia II runs
  about 4% slower uncapped on the M1 Max as a result (still over 100 fps).
