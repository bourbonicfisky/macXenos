# macXenos 1.0 beta 8 — release notes

macXenos is an unofficial macOS port of Xenia Canary with a native Metal
rendering backend. This build is tagged `macxenos-1.0-beta8` on the
`codex/metal-foundation-integration` trunk. It follows beta 7 (2026-10-30);
see `1.0-beta7.md` for everything beta 7 added.

## What changed since beta 7

### Graphics fixes

- **Banjo-Kazooie: Nuts & Bolts: the dirt path is back.** In the Spiral
  Mountain intro and in play, grass tufts covered the path from Banjo's
  house and floated over the ground. The game hides each tuft that sits on
  bare ground; Metal was ignoring that, so every tuft was drawn.
- **Dishonored and Mafia II: objects no longer pop in and out.** Lamp
  glows, people in doorways and whole buildings flashed on and off. Both
  games now wait for real occlusion results (a built-in per-game setting),
  and the draws those results count now run on Metal. Assassin's Creed's
  fading crowds got the same setting. Mafia II stays uncapped.
- **Dishonored: a heavy loading frame no longer drops draws.** Very large
  frames used to run out of upload space; macXenos now hands the work to
  the GPU in smaller pieces.
- **Dragon Age: Origins** draws its world, bodies and faces (flat untextured
  planes, missing bodies, a band over every face and magenta gauntlets are
  gone).
- **Tiger Woods PGA Tour 06:** no grey-lavender band across the lower part
  of the picture.
- **Virtua Tennis 4:** menu text and textures no longer show as noise.
- **Fewer random missing draws** in Saints Row, Tekken Tag Tournament 2,
  LEGO Batman, NBA 2K14, Bad Company, Lost Planet: Colonies, Test Drive
  Unlimited and others (a shader was sometimes used before it was ready).

### Speed

- **NBA 2K11:** 16.8 -> 60 fps on the M4 mini, 11.7 -> 17 fps on the M1 Max
  (faster translated vector code).
- **NBA 2K18:** 9.5 fps -> full speed.
- **Iron Man:** title screen and menus at 60 (were 39-45 on the M1 Max).
- **Super Street Fighter II Turbo HD Remix:** 60 on the M1 Max (was locked
  at 30).
- **WALL-E:** full-screen videos play at full speed (were 2.6 fps).

### Stability

- **NBA Street Homecourt** no longer hangs on boot (about 1 boot in 3).
- **Crysis 3** no longer freezes mid-game (about 1 run in 5).
- **Fable III** and **Black Ops III** no longer exit with
  "Overflowed stackpoints!".
- **Bully**, **Battlefield: Bad Company** and **WWE SmackDown vs. Raw 2011**
  no longer crash at boot or the first load.
- **NBA Ballers: Chosen One** boots (built-in patch).

### Intel Macs

- The Intel/AMD Metal pipeline is merged: Macs with more than one GPU use
  the discrete one, texture memory limits follow its VRAM, and shared
  memory stays in VRAM (Mac Pro: Red Dead Redemption 22.6 -> 28 fps,
  Gears of War 3 23.3 -> 30). The minimum is a Radeon RX 580 with 4 GB.

## Known issues

- Tiger Woods PGA Tour 14 crashed once and stalled on its first screen once
  in 10 boots on the M4 mini (not seen on the M1 Max); the cause is not yet
  known.
- Prince of Persia: The Forgotten Sands still hangs at its first loading
  screen on about half of boots (also on Vulkan and on Intel).
- See `docs/dev/title_issues.md` for the full per-game list.
