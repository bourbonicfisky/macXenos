# macXenos 1.0 beta 6 — release notes

macXenos is an unofficial macOS port of Xenia Canary with a native Metal
rendering backend. This build is tagged `macxenos-1.0-beta6` on the
`codex/metal-foundation-integration` trunk. It follows beta 5 (2026-10-28);
see `1.0-beta5.md` for everything beta 5 added.

## What changed since beta 5

### Your files

- **Moving to the new folders finishes even if it was interrupted.** The
  copy of the old storage folder (`~/.local/share/Xenia`) gave up for good if
  the first launch stopped after copying the config, and saved games stayed
  behind whenever `Documents/macXenos/Saves` already existed, even empty, so
  they looked lost (the originals were never deleted). Both now carry on at
  each launch until they are done, never overwrite a file already in the new
  place, and only remove a moved save once the new copy is identical. If
  something cannot be moved, an alert says what and that nothing was
  deleted.

### Faster games, less stutter

- **Less stutter the first time a game shows something new.** Pipelines
  now build in the background while the frame goes on: on a first session
  after an update, Mafia II's in-play pauses on an M4 mini went from 9.1 to
  0.9 s, and Rise of the Tomb Raider's were roughly cut in half.
- **GTA IV reaches 60 fps on an M4 mini** (54 in beta 5): resolved textures
  are written straight into the texture that reads them instead of being
  reloaded, and draws that cover a whole target skip restoring it first.
- **Resolution scaling (2x) is faster.** Copies of the picture now read the
  render target directly at any scale, and multisampled targets are saved
  and restored faster. At 2x on an M4 mini: Ultra Street Fighter IV 32.5 ->
  38.2 fps, Gears of War: Judgment 18.2 -> 22.1, Resident Evil 5 23.4 ->
  25.4, GTA IV 18.9 -> 21.3; on an M4 Pro GTA IV 40 -> 43.9.

### Fixes

- **F.E.A.R.:** the red gun (a texture showed stale data after the game
  reused its memory). This also looks to have cured the green flashes in
  its menus; tell us if you still see them.
- **Assassin's Creed II:** the washed-out corridor (the game now waits for
  occlusion query results).
- **Games on a network share** no longer crash or freeze at boot when the
  disc image is slow to read (GTA IV from an SMB share).

### Packaging

- **The bundled Vulkan loader now runs on macOS 15.** Beta 5's Apple
  Silicon copy required macOS 27, so the Vulkan backend (not the default
  Metal one) could not start on older macOS. The packager now refuses any
  bundled library that needs a newer macOS than the app.
